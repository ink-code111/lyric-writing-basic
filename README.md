# lyric-writing-basic — 歌词创作技能（基础版·免费）

中文歌词从零创作与润色的 AI 技能：定钩子与视角、规划结构与情绪曲线、十三辙选韵、自检清单把关，交付歌词 + 创作说明 + 候选标题。单文件即装即用。

## 能做什么

- **从零创作**：中文流行/民谣歌词——定核心概念与钩子、定视角、规划段落结构与情绪曲线、定韵脚方案、逐段落笔、自检把关；
- **润色改写**：先诊断后动笔，把"太平了/不抓耳"翻译成具体问题，逐条说明改动理由，保留原作语感；
- **内置十三辙韵表速查**：韵辙、韵母、示例字、响度分级，选韵不抓瞎。

- 婚礼/生日/毕业/告白等场合定制歌（专属细节入词，副歌保持普适）
- Suno 等 AI 音乐平台格式适配（标签规范、Style 字段、平台可用版）
- 依声填词（一字一坑、段间句式对齐、粤语协音）
